# 分流标签

使用五个默认分流角色；本地规格和任务在顶部附近以 `Status: <label>` 记录。

| 分流角色 | 本项目标签 | 含义 |
| --- | --- | --- |
| needs-triage | needs-triage | 等待维护者评估 |
| needs-info | needs-info | 等待补充信息 |
| ready-for-agent | ready-for-agent | 规格充分，可交给代理实施 |
| ready-for-human | ready-for-human | 需要人工实施 |
| wontfix | wontfix | 不予实施 |

技能要求应用某个分流角色时，使用本表对应的标签。用户希望更换标签时更新本表及相关任务，不创建同义重复标签。

`ready-for-agent` 表示规格已具备实施条件，不表示代码已完成或设备验收已通过。
