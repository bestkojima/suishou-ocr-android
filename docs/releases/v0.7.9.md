随手识别 0.7.9 预发布版

本次改进：

- 修复发票等表格在识别过程中正常、识别完成后显示错误的问题：恢复引擎保留的原始表格输出，支持合并单元格和校对；未通过校验的结果仍显示待核对提示。
- 添加模型循环输出保护：生成期间检测持续重复和连续空编号，提前停止退化输出并保留核对提示，避免一直生成；不改变采样、提示词或视觉配置。
- 校对新增“重新识别此区域”：可选择已下载的 Ovis 或 GLM，仅识别当前文字、表格或公式区域。本次模型选择不修改全局默认模型。
- 新识别结果先供预览，点击“使用此结果校对”后填入草稿，再保存修改才替换当前区域。支持取消和关闭后重开，保留其他区域、已有校对与原始 JSON。
- 整理工程结构，统一回放状态机、样本来源和网页打包入口，移除过时原型工程，保留历史验证记录。

验证：两版各 82 项 JVM 测试通过，网页交互、发票表格与实时识别回归通过。原生区域识别、循环停止、取消和预算测试通过；Ovis、GLM 的 Linux 同源真实裁图识别已验证。发布前再次运行两版构建、lint、APK ABI/依赖/签名/版本检查，原生保持 Release／-O3／NDEBUG，use_mmap=false、kvcache_mmap=false。

安装包：

- `suishou-ocr-0.7.9-arm64.apk`：普通版。
- `suishou-ocr-0.7.9-lab-arm64.apk`：测试版，包含诊断入口。
- `SHA256SUMS.txt`：本地生成的安装包校验值。

需要 Android 8.0+ / arm64-v8a。APK 不包含模型，识别前需完成模型下载。两版沿用原应用标识与 Debug 签名，可覆盖安装对应旧版并保留模型和记录。

尚待手机验收：WebView/JNI 全链路体验、模型切换内存峰值、取消延迟，以及 Titan_1 性能与内存。Linux 实测不能替代手机验收；循环保护不保证识别内容正确，也不表示 BUG-002 的所有根因已经解决。其他未明确修复的问题沿用 bugdoc.md。
