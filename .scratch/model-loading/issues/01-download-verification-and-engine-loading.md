Status: ready-for-agent

用户要求：模型内容校验只在下载完成时执行；加载模型参照 MNN Chat 的实现。实施完成情况独立于分流标签记录。

- [x] 下载完成且 SHA 校验成功后记录最终文件的校验值、大小与修改时间。
- [x] 加载只检查已校验下载记录与文件元数据，不重新扫描权重；兼容旧版已校验下载记录。
