- MNN 写入输出流时发布实际正文，保留最终原文和公共 C ABI 行为。
- 按作业、区域与尝试隔离快照；中文／emoji 字节拆分不造成乱码；重试替换该区域正文。

- 表格和公式未闭合时展示实时原文，区域结束后正常排版。最终资源与校对、排序、导出在保存后开放。
- 记录首内容、视觉、prefill、decode、token 数与总耗时。基于实际代码和计时说明 CPU 配置；未经设备测量不预设多线程／GPU 会更快。
