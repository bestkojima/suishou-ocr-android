# 单图输入分辨率与解码成本

Status: ready-for-agent

用户反馈：原图是否没有分辨率处理，导致真实识别过慢。

- 明确原图规范化、版面模型固定 800×800 和 OCR 区域像素预算三个边界。
- 使用 bounds 和 inSampleSize 在 Android 解码前规划，解码后按比例缩小再做 EXIF 1～8；不放大小图。
- 默认均衡：长边 4096、总像素 800 万；快速：长边 2560、总像素 400 万；原图保留尺寸。三者仍拒绝超过 6400 万像素。
- 保留导入的原文件；重识别复制原文件与输入元数据，新结果不覆盖旧记录。策略改变时由原文件再生成输入。
- 旧待识别记录也执行规范化；没有原文件时使用保存的 source。识别图片、页面、资源尺寸与 native 坐标一致。
- 设置在每项作业开始时固定，对下次识别生效。保存规范化版本、策略、原始／解码／输入尺寸、采样倍率和耗时，避免同策略反复处理。
- 比较真实模型大图／均衡／快速的完整结果与耗时，显式区分 Linux 同源推理与 Android Bitmap／设备验证。
