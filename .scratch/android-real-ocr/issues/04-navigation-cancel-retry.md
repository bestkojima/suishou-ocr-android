# 04: 贯通导航、取消和失败重试

**What to build:** 用户在识别中返回首页或重开文档仍能看到同一作业；显式取消会等待安全停止，失败和取消保留输入并提供重试。应用进程退出后可重新开始识别，模型管理不会破坏正在运行的作业。

**Blocked by:** 02：打通单张图片真实识别和结果展示

**Status:** ready-for-agent

- [x] 返回首页不取消后台识别，再次打开文档可恢复当前作业状态；作业管理不依赖结果页是否存在。
- [x] 取消请求与同步推理解耦，立即显示取消中，并等待原生执行、必要恢复和清理到达终态后才显示已取消。
- [x] 取消中不能启动第二个作业或销毁仍被推理使用的资源；正常完成、失败和取消均可释放后再执行后续任务。
- [x] 失败和取消保留输入并支持重试；原生没有有效结果时不会伪造取消作业的已识别正文。
- [x] 迟到、重复以及切换文档后的事件按作业归属处理，不污染其他文档或当前页面。
- [x] 进程终止后的输入仍可打开并重新识别，不把遗留运行状态当成活跃作业，不承诺从区域中间续推理。
- [x] 使用中的模型删除同时在公开操作和界面受到保护；安全删除后重新检查就绪状态，下一次识别需要模型仍可用。
- [x] 通过公开桥接行为验证导航、运行冲突、安全取消、失败/取消后重试及模型删除保护；同引擎桌面重复作业证据单独记录，设备生命周期验收保留待办。
