# 03: 贯通结构化结果、校对、排序和导出

**What to build:** 用户识别含公式、表格或图片的单页后，能正确阅读全部结构化内容及部分成功提示，进行校对和阅读顺序调整，保存到历史并导出或重新导入；重新识别另存新记录，旧结果和校对保持完整。

**Blocked by:** 02：打通单张图片真实识别和结果展示

**Status:** ready-for-agent

- [ ] 适配真实 DocumentIR 的文字、Markdown、LaTeX、HTML 表格和图片资源，按阅读顺序展示并保留原图核对。
- [ ] 支持实际 schema 变体，保留原始结果与元数据，不假定展示区域、LayoutBlock 和 Region 一一对应。
- [ ] partial 结果保存可用内容和未完成区域状态；空白、部分成功与失败可区分，不把 API 成功返回当作全页正确。
- [ ] 资源引用、尺寸和本地图片展示正确，历史重开后内容及图片保持可用；表格/公式沿用既有完整区域展示。
- [ ] 已完成展示区域可校对和同页排序，区域标识维持内容、图片、校对和阅读位置关联，App 重启后仍恢复。
- [ ] TXT、Markdown 及 ZIP 按当前阅读顺序和校对导出；ZIP 保留有效原始 DocumentIR 与资源，重新导入能恢复应用校对信息。
- [ ] 原始模型输出和用户修正分别保存，不无条件回写或自动迁移到新区域标识。
- [ ] 前一成功作业终止后重新识别同一输入形成新记录，旧结果与校对不变；新旧文档资源不相互覆盖，仍遵守一次一项规则。
- [ ] 使用真实结构化/partial 输出复用文档归一化、存储、阅读顺序、浏览器渲染和导出再导入测试；证据注明真实内容来源及原生模拟边界。
- [ ] 本任务的成功作业重识别不等待取消功能；取消后的重识别组合场景纳入最终交付验证。
