# 02: 打通单张图片真实识别和结果展示

**What to build:** 模型就绪后，用户拍照或导入一张文字图片即可自动开始本地真实识别，看到实际阶段进度，并在完整结果保存后进入现有结果展示与历史记录。这是第一条从新输入到模型产出正文的完整识别路径。

**Blocked by:** 01：打通输入保存、模型准备与本地引擎激活

**Status:** ready-for-agent

- [x] 拍照和单图导入先保存输入，再在模型就绪时自动识别；已有待识别输入可显式启动，缺模型继续保留输入。
- [x] 推理前规范 EXIF 旋转及镜像，使用非对称图片验证方向；原图显示、推理尺寸与结果几何保持一致。
- [x] 实际调用 docprase 生产管线，单图成功输出有效 DocumentIR、Markdown 与引用资源；结果不来自样本回放或伪造文本。
- [x] 公开事件具有稳定作业标识和关联文档，显示准备、识别和终态；正文落盘后复用既有逐步展示，清楚区分识别与结果回放。
- [x] 原始结果及归一化文档可从历史重新打开，阅读顺序和展示区域标识保持稳定。
- [x] 只允许一个活跃作业，第二个启动请求明确报告冲突；旧作业和重复事件不会覆盖当前文档。
- [x] 后台推理不阻塞状态读取或界面；暂停结果展示只作用于回放。
- [x] 当前环境用同一引擎对新的文字样图真实推理，验证结果适配，并提供 Android 构建及模拟桥接/UI 证据；APK 内推理是否成功仍留待设备确认。
