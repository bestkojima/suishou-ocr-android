# 发票表格终态显示与循环输出保护

Status: ready-for-agent

用户于 2026-10-13 要求修复发票常见表格显示异常，并添加循环输出检测；补充症状为「识别途中正常，识别完成后显示错误」。本次授权覆盖生产检测与提前停止，取代此前 BUG-002 仅诊断的限制。

## 验收要求

- 部分识别表格的正文被引擎清空时，从 DocumentIR `provenance.raw_output` 恢复展示/校对原文，保留原始 JSON 和待核对状态。
- 合并单元格、正常和异常公式不阻止校对；校对保存与重新打开一致。
- 模型生成期间检测持续短片段/标点循环及连续空编号，停止后续解码；保留截停前的原始输出和停止原因，不扩大 token 预算重试。
- 正常重复表格行和带正文的题号不能误停；下一识别区域重置保护状态；取消优先于检测结果。
- 不改变采样、提示词、分辨率或模型配置；保留原 token/时间上限。

## 范围
