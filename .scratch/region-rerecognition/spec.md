# 校对时切换模型重新识别当前区域

Status: ready-for-agent

用户要求在校对选项中添加重新识别，可选择另一模型处理识别错误的区域。

- 使用所选展示区域已经保存的裁图和文字/表格/公式类型，直接调用区域识别，不重新进行整页版面分析。
- 列出受支持模型及文件就绪情况；本次模型选择不改变全局默认值。串行使用引擎，切换前释放旧模型，保留循环输出保护。
- 新结果先作为候选显示，选择使用后进入校对草稿；只有保存修改才更新当前区域。失败、取消、关闭校对不覆盖旧内容，原始 JSON 与其他区域不变。
- 长任务显示状态并支持取消；关闭或切换区域后迟到响应不得写入其他区域。进程退出后恢复为已中断，不伪装完成。
- 无裁图/不支持类型明确不可重识别；浏览器仅预览，实际推理在 APK 内离线执行。

## Comments

只修改 Android 自有接口、任务控制及校对界面；不改变 docprase 公共 ABI。验证见 verification/region-rerecognition/DELIVERY.md。
