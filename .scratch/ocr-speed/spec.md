# 本地 OCR 识别速度与模型复用

Status: ready-for-agent

用户要求：调查是否每个区域重载模型，并思考、实施实际提速。

- 区分加载权重、区域会话 reset、视觉处理、prefill 和 decode，不把逐字展示速度当作计算速度。
- 每张图只创建／释放作业，保留已加载的引擎及运行缓存；改动模型、实际线程数变化、系统内存压力或退出 App 时安全卸载。
- 保留单作业和区域会话隔离；禁止跨区域盲目复用 KV，禁止并发执行同一不支持隔离会话的引擎。
- 支持 CPU 自动／1／2／4 线程，自动最多4并受可用CPU数限制。版面、语言和视觉后端采用实际计划；manifest、模型profile和流式计时记录真实线程数。
- 比较真实模型的冷启动与连续识别，并验证正文一致；桌面速度不能代替 Android 设备测量。
- 保留模型下载时校验、加载时不扫描 SHA，以及真实流式渲染。
