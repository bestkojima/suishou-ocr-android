# BUG-005：拍照后的文档裁剪确认

Status: ready-for-agent

2026-10-09：用户授权实施 BUG-005。

拍照后保留原始照片，先自动检测文档边界，再允许用户拖动四角或移动整个裁剪框。用户预览并确认后才启动 OCR。检测失败时回退到整张照片并允许手动选框；取消不启动识别，可以重新拍照或从历史恢复裁剪。

采用现有 Camera2、React/WebView 和私有文档存储，使用固定版本 OpenCV 4.12.0 进行轮廓检测和透视校正，不引入另一套相机界面。`zynkware/Document-Scanning-Android-SDK` 为交互参考。预览与识别使用同一份确认后的裁剪图片；调整分辨率及重新识别不得恢复背景。

验收：自动检测、手动四角/整框拖动、全图回退、预览/确认、取消/重新拍照、历史恢复、重新裁剪另存、原照片保留、连续识别与导出兼容。设备交互与实际检测效果需真机复测。
