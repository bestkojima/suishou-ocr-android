# 一键发布脚本交付记录

2026-10-09，针对用户“一键构建发布提交，上传成功后不要复核”的要求。

- 入口：[tools/release.py](../../tools/release.py)。一个命令递增版本、保存中文改进说明、构建两版、执行本地检查、提交全部未忽略改动、原子推送来源提交和标签、发布三项资产。
- 默认 GitHub 预发布；普通版／测试版保持原应用标识和签名，原生 Release 与 mmap=false 约定不变。1.0.0 及以上必须明确使用 `--stable`。
- `SHA256SUMS.txt` 在上传前生成；上传成功后没有额外外部命令，不查询远端资产、不下载、不进行上传后 SHA 比对。
- 提交后的推送或上传失败可从本地状态续传；已发布状态直接返回保存的地址，不联网。直接杀死进程造成的远端状态不确定在文档中明确说明。
- [使用说明](../../docs/RELEASE.md)、README 和 MEMORY 已更新，旧版本发布复核证据保留为历史记录。
